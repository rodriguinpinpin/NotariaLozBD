# Sistema Operativo para la Notaría Lozano

## Descripción del proyecto

Proyecto académico desarrollado en el curso de Base de Datos Avanzadas y Big Data, correspondiente al período 2026-2 de la carrera de Ingeniería de Sistemas Computacionales.

El proyecto tiene como objetivo implementar y evaluar una solución integrada de Inteligencia de Negocios (BI) y Big Data para la Notaría Lozano, orientada a optimizar la gestión de trámites notariales, la búsqueda de antecedentes documentales y el análisis de información para la toma de decisiones.

## Tecnologías utilizadas

- **Microsoft SQL Server 2022:** gestión de la base de datos transaccional y modelos dimensionales.
- **Power BI Desktop:** elaboración de reportes e indicadores de gestión.
- **Windows 11:** sistema operativo del entorno de desarrollo.
- **GitHub:** repositorio para el control de versiones.
- **SharePoint:** almacenamiento colaborativo del informe y diagramas del proyecto.

La herramienta específica de procesamiento Big Data se encuentra pendiente de identificación.

## Archivos SQL del proyecto

- `Base De Datos Notaria(Completo) (1).sql`: estructura de la base de datos transaccional.
- `INGRESO DE DATOS.sql`: inserción de registros.
- `IngresoDatos(NuevasEntidades).sql`: incorporación de registros de nuevas entidades.
- `MODELOS ESTRELLA.sql`: creación de los modelos dimensionales.
- `vistas.sql`: creación de vistas para consultar la información.

## Inteligencia de Negocios

La solución BI contempla el uso de modelos dimensionales y reportes en Power BI para analizar información relacionada con los trámites notariales.

El proyecto Power BI proporcionado por el equipo contiene páginas de análisis financiero, operativo y documental.

## Requisitos del entorno

- Sistema operativo: Windows 11.
- Memoria RAM del equipo utilizado: 16 GB.
- Gestor de base de datos: Microsoft SQL Server 2022.
- Herramienta de visualización: Power BI Desktop.

El procesador, la versión exacta de Power BI y las dependencias del entorno Big Data están pendientes de documentar.

## Instalación y ejecución

Para reproducir la solución BI será necesario disponer de SQL Server 2022, ejecutar los scripts correspondientes a la base de datos y disponer del proyecto de Power BI.

El orden definitivo de ejecución de los scripts, las configuraciones de conexión y los procedimientos de validación se encuentran pendientes de documentación.

## Reproducibilidad experimental

El informe contempla tres escenarios experimentales:

- EXP-01: evaluación de la solución BI.
- EXP-02: evaluación de la solución Big Data.
- EXP-03: evaluación comparativa de la solución integrada.

Las pruebas consideran métricas de latencia y capacidad de procesamiento en tres niveles de volumen de datos. Las configuraciones de ejecución, cantidades de registros, repeticiones y resultados deben incorporarse cuando se encuentren disponibles.
